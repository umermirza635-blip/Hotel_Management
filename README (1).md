# 🏨 Hotel Booking System

## 📌 Project Description
The Hotel Booking System is a Java-based application designed to automate hotel operations such as room management, booking, and customer handling.

Sprint 1: Authentication and room management  
Sprint 2: Booking system, availability, and payment simulation  
Sprint 3: Check-in/check-out, cancellation, invoice generation, reviews, and UI improvements  

---

## ⚙️ How to Run (VS Code)

1. Extract the zip file: hotel_management-D3(1).zip  
2. Open the folder in VS Code  
3. Install JDK and Java Extension Pack  
4. Open terminal in VS Code  
5. Compile the program:
   javac *.java  
6. Run the program:
   java Main  

*(Replace 'Main' with actual main class if different)*
